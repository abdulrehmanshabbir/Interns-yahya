Python Assessment — Interns

Answer all questions. For coding problems, write clean, working Python.

Section A — Multiple Choice (choose one)

  1. What is the output of print(type([]))?

    • a) <class 'list'>
    • b) <class 'array'>
    • c) list
    • d) <list>

  2. Which of these is immutable?

    • a) list
    • b) dict
    • c) set
    • d) tuple

  3. What does len("hello") return?

    • a) 4
    • b) 5
    • c) 6
    • d) error

  4. Which keyword defines a function?

    • a) func
    • b) def
    • c) function
    • d) define

  5. What is the result of 3 // 2?

    • a) 1.5
    • b) 1
    • c) 2
    • d) 1.0

  6. How do you start a single-line comment in Python?

    • a) //
    • b) /*
    • c) #
    • d) --

  7. What does range(3) produce?

    • a) 1, 2, 3
    • b) 0, 1, 2
    • c) 0, 1, 2, 3
    • d) 0, 1

  8. Which list method adds an item to the end of a list?

    • a) add()
    • b) append()
    • c) push()
    • d) insert()

Section B — Predict the Output / Short Answer

  1. What does print(2 ** 3) output?

  2. What is the output of print("ab" * 3)?

  3. Given d = {'a': 1, 'b': 2}, what does print(list(d.keys())) output?

  4. What does bool("") return, and why?

  5. Explain the difference between == and is.

  6. What is a list comprehension? Write one that produces the squares of the numbers 0 through 4.

Section C — Coding Problems (write a function)

  1. Write a function is_even(n) that returns True if n is even, otherwise False.

  2. Write a function reverse_string(s) that returns the string reversed.

  3. Write a function count_vowels(s) that returns the number of vowels in s.

  4. Write a function fizzbuzz(n) that prints the numbers from 1 to n, but prints "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for multiples of both.
